# Заняття 11. Нейронні мережі, комп'ютерний зір та обробка зображень у Python

Коли людина дивиться на фотографію, вона миттєво розуміє: *«Ось тут сидить рудий кіт, а на задньому плані — дерево»*. Для комп'ютера ж будь-яке фото — це просто величезна таблиця з мільйонів чисел (кольорів окремих пікселів), у якій спочатку немає жодного сенсу. Навчити програму «розуміти» картинки, знаходити на них обличчя чи предмети та змінювати їх дозволяє галузь **комп'ютерного зору (Computer Vision)** і технологія **нейронних мереж**.

---

## 1. Як комп'ютер «бачить» зображення?

Перед тим як розбиратися з нейронними мережами, важливо зрозуміти, як саме картинка зберігається в пам'яті комп'ютера:
1. **Пікселі та матриця:** будь-яке цифрове зображення складається з найменших точок — **пікселів**, розташованих у вигляді сітки (матриці) шириною $W$ та висотою $H$. Наприклад, фото розміром $1000 \times 1000$ містить 1 мільйон пікселів.
2. **Колір як набір чисел:** колір кожного пікселя кодується трьома числами від `0` до `255` (де `0` — повна відсутність кольору, а `255` — максимальна яскравість):
   * **R** (Red — червоний)
   * **G** (Green — зелений)
   * **B** (Blue — синій)
   * *Приклад:* `(255, 0, 0)` — яскраво-червоний піксель, `(0, 0, 0)` — чорний, `(255, 255, 255)` — білий.
3. **Система координат на зображенні:** на відміну від шкільних уроків математики, у комп'ютерній графіці точка початку координат **`(0, 0)` розташована у верхньому лівому куті** екрана:
   * координата **`X`** зростає **зліва направо**;
   * координата **`Y`** зростає **зверху вниз**.

## 2. Що таке нейронні мережі та як вони працюють?

### Чому звичайне програмування тут не працює?
У класичному програмуванні ми пишемо чіткі правила: `if температура > 30: увімкнути кондиціонер`. Але неможливо написати `if` для розпізнавання кота на фото — коти бувають різних порід, кольорів, у різних позах і при різному освітленні.

**Штучна нейронна мережа (ШНМ)** — це алгоритм машинного навчання, побудований за аналогією з людським мозком. Замість жорстких правил програміста мережа сама вивчає закономірності, проаналізувавши тисячі або мільйони фотографій із підписами («це кіт», «це не кіт»).

### Як влаштована нейронна мережа (на простому прикладі)
Уявіть команду детективів, де кожен відповідає за свою маленьку підказку:

1. **Нейрони (вузли):** це базові «обчислювачі». Кожен нейрон приймає на вхід кілька чисел, виконує над ними просте обчислення і передає одне число далі.
2. **Шари нейронів (Layers):** нейрони вишикувані в кілька послідовних рядів:
   * **Вхідний шар (Input Layer):** приймає сирі дані — значення яскравості пікселів фотографії.
   * **Приховані шари (Hidden Layers):** працюють крок за кроком від простого до складного:
     * *1-й прихований шар* знаходить найпростіші елементи: світлі й темні лінії, краї, кути.
     * *2-й прихований шар* об'єднує лінії у прості форми: кола (очі), трикутники (вуха), овали.
     * *3-й прихований шар* збирає з цих форм цілі частини об'єкта: мордочку, вуса, силует голови.
   * **Вихідний шар (Output Layer):** підбиває підсумок і видає фінальну відповідь (наприклад: *«імовірність того, що це кіт — 98%»* та координати, де саме він розташований).
3. **Синапси та ваги (Weights):** зв'язки між нейронами сусідніх шарів. Кожен зв'язок має коефіцієнт важливості — **вагу**. Якщо для визначення кота форма вух важливіша за колір фону, вага зв'язку від нейрона «трикутні вуха» буде великою, а від нейрона «колір шпалер» — близькою до нуля. Навчання нейромережі якраз і полягає в тому, щоб автоматично підібрати правильні ваги для всіх зв'язків.
4. **Функція активації (Activation Function):** спеціальне математичне правило всередині кожного нейрона. Вона перевіряє, чи достатньо сильний сигнал надійшов на вхід, і перетворює його у зручний діапазон (наприклад, від `0` до `1`), вирішуючи, чи варто «вмикати» цей нейрон і передавати сигнал далі.

## 3. Бібліотека `OpenCV`: встановлення та базове використання

**OpenCV (Open Source Computer Vision Library)** — найвідоміша у світі професійна бібліотека для роботи із зображеннями та відео. Вона написана мовою **C/C++** (тому працює надзвичайно швидко навіть із відеопотоком з веб-камери в реальному часі), а для Python має зручний модуль **`opencv-python`**.

### Встановлення та підготовка проєкту
1. У терміналі PyCharm виконайте команду встановлення:
```bash
   pip install opencv-python

```

2. Усі робочі файли (`cat.jpeg`, `glasses.png`, `haarcascade_frontalcatface_extended.xml`) покладіть у **ту саму папку проєкту**, де лежить ваш `.py` файл (і називайте їх латиницею, без кирилиці та пробілів у шляху).
3. У коді бібліотека завжди імпортується як **`cv2`**:
```python
import cv2

```



### Особливість форматів кольору в `OpenCV`

Більшість програм зберігають колір у порядку **RGB** (Червоний, Зелений, Синій). Проте історично склалося, що `OpenCV` читає кольори у зворотному порядку — **BGR** (Синій, Зелений, Червоний):

* `(255, 0, 0)` в OpenCV — це **синій** колір.
* `(0, 255, 0)` в OpenCV — це **зелений** колір.
* `(0, 0, 255)` в OpenCV — це **червоний** колір.

### Практика 1: Відкриття та показ зображення

Щоб завантажити картинку та показати її у вікні, використовуються три базові функції:

* `cv2.imread(path)` — зчитує зображення з диска у вигляді числового масиву пікселів.
* `cv2.imshow(title, image)` — створює вікно на екрані та відображає в ньому картинку.
* `cv2.waitKey(0)` — зупиняє виконання програми й чекає, поки користувач натисне будь-яку клавішу (без цього рядка вікно відкриється і миттєво закриється).

```python
import cv2

image_path = "cat.jpeg"
image = cv2.imread(image_path)

cv2.imshow("Cat", image)
cv2.waitKey(0)

```

### Практика 2: Пошук мордочки кота та малювання рамки

Для швидкого пошуку об'єктів в `OpenCV` використовуються заздалегідь навчені моделі — **каскади Хаара (Haar Cascades)**, збережені у вигляді `.xml`-файлів (наприклад, `haarcascade_frontalcatface_extended.xml`).

1. **`cv2.CascadeClassifier(xml_path)`** — завантажує навчену модель розпізнавання.
2. **`classifier.detectMultiScale(image)`** — сканує зображення у різних масштабах і повертає список прямокутників для всіх знайдених об'єктів у вигляді **чотирьох чисел `(x, y, w, h)**`:
* **`x`**, **`y`** — координати верхнього лівого кута мордочки;
* **`w` (width)** — ширина знайденої області;
* **`h` (height)** — висота знайденої області.


3. **`cv2.rectangle(image, (x1, y1), (x2, y2), color, thickness)`** — малює прямокутник поверх зображення за координатами верхнього лівого `(x, y)` та правого нижнього `(x + w, y + h)` кутів.

```python
import cv2

image_path = "cat.jpeg"
cat_face_cascade = cv2.CascadeClassifier("haarcascade_frontalcatface_extended.xml")

image = cv2.imread(image_path)
cat_face = cat_face_cascade.detectMultiScale(image)

for (x, y, w, h) in cat_face:
    # Малюємо червону рамку (BGR: 0, 0, 255) товщиною 3 пікселі
    cv2.rectangle(image, (x, y), (x + w, y + h), (0, 0, 255), 3)

cv2.imshow("Cat", image)
cv2.waitKey(0)

```

## 4. Бібліотека `Pillow` (`PIL`): встановлення та робота із зображеннями

`OpenCV` чудово знаходить координати об'єктів, але накладати поверх фото картинки з прозорим фоном (наприклад, піксельні окуляри, стікери чи маски) набагато зручніше за допомогою бібліотеки **`Pillow`**.

### Встановлення та імпорт

1. У терміналі виконайте:
```bash
pip install pillow

```


2. У коді бібліотека імпортується з модуля **`PIL`** (назва спадкувалася від старої версії бібліотеки *Python Imaging Library*):
```python
from PIL import Image

```



### Навіщо потрібен режим `"RGBA"`?

Звичайна фотографія (`.jpg`) має режим **`RGB`** — у ній кожен піксель непрозорий. Якщо накласти поверх кота звичайну картинку окулярів у форматі `RGB`, навколо окулярів буде суцільний білий або чорний прямокутник, який закриє пів мордочки.

Картинки формату `.png` підтримують режим **`RGBA`**, де четверта літера **`A` (Alpha-канал)** відповідає за прозорість:

* там, де мають бути самі окуляри, прозорість дорівнює `0%` (вони повністю видимі);
* там, де порожній фон навколо окулярів, прозорість дорівнює `100%` (крізь них видно кота).

### Основні методи об'єкта `Image` у `Pillow`

| Метод | Призначення | Особливості використання |
| --- | --- | --- |
| **`Image.open(path)`** | Відкриває файл зображення | Повертає об'єкт зображення, готовий до редагування. |
| **`.convert(mode)`** | Змінює кольоровий режим | Передає рядок `"RGBA"` або `"RGB"`, щоб обидва зображення мали однаковий формат перед накладанням. |
| **`.resize((width, height))`** | Змінює розмір зображення | Приймає **кортеж із двох цілих чисел** `(нова_ширина, нова_висота)`. Дробові значення потрібно приводити до `int()`. |
| **`.paste(im, box, mask)`** | Накладає одне зображення на інше | `im` — що накладаємо; `box` — кортеж координат верхнього лівого кута `(x, y)`; `mask` — маска прозорості (передаємо сам об'єкт `RGBA`-зображення, щоб прозорі пікселі не затирали фон). |
| **`.save(path)`** | Зберігає результат у файл | Формат визначається автоматично за розширенням файлу (`.png`, `.jpg`). |

### Практика 3: Поєднання `OpenCV` + `Pillow` (накладання окулярів на кота)

Логіка розрахунку розмірів та позиції окулярів за знайденими координатами `(x, y, w, h)`:

* **Ширина окулярів** дорівнює ширині мордочки `w`, а **висота** пропорційно зменшується до `int(h / 3)`.
* **Координата по горизонталі (`X`)** залишається `x` (лівий край мордочки).
* **Координата по вертикалі (`Y`)** зміщується вниз на чверть висоти мордочки: `int(y + h / 4)`, оскільки очі розташовані у верхній третині голови, нижче вух.

```python
import cv2
from PIL import Image

image_path = "cat.jpeg"
cat_face_cascade = cv2.CascadeClassifier("haarcascade_frontalcatface_extended.xml")

# 1. Знаходимо координати мордочки за допомогою OpenCV
image = cv2.imread(image_path)
cat_face = cat_face_cascade.detectMultiScale(image)

# 2. Відкриваємо зображення через Pillow та вмикаємо альфа-канал (прозорість)
cat = Image.open(image_path).convert("RGBA")
glasses = Image.open("glasses.png").convert("RGBA")

# 3. Для кожної знайденої мордочки підганяємо окуляри та накладаємо їх
for (x, y, w, h) in cat_face:
    resized_glasses = glasses.resize((w, int(h / 3)))
    cat.paste(resized_glasses, (x, int(y + h / 4)), resized_glasses)

# 4. Зберігаємо результат і виводимо на екран
cat.save("cat_with_glasses.png")
result = cv2.imread("cat_with_glasses.png")
cv2.imshow("Cat with glasses", result)
cv2.waitKey(0)

```

## 5. Шпаргалка: хто за що відповідає у зв'язці `OpenCV + Pillow`

| Етап задачі | Яка бібліотека використовується | Який метод викликається | Що відбувається |
| --- | --- | --- | --- |
| **1. Завантаження каскаду** | `OpenCV` (`cv2`) | `cv2.CascadeClassifier(...)` | Завантажується навчена модель для пошуку мордочок котів. |
| **2. Пошук мордочки** | `OpenCV` (`cv2`) | `.detectMultiScale(...)` | Нейромережа знаходить кота і повертає координати `(x, y, w, h)`. |
| **3. Підготовка картинок** | `Pillow` (`Image`) | `Image.open()`, `.convert("RGBA")` | Відкриваються фото кота та окулярів, вмикається підтримка прозорості. |
| **4. Масштабування** | `Pillow` (`Image`) | `.resize((w, int(h/3)))` | Окуляри підганяються точно під ширину знайденої мордочки. |
| **5. Накладання маски** | `Pillow` (`Image`) | `.paste(..., (x, int(y+h/4)), ...)` | Окуляри накладаються точно на рівень очей із прозорим фоном. |
| **6. Збереження та показ** | `Pillow` + `OpenCV` | `.save()`, `cv2.imshow()`, `cv2.waitKey()` | Зберігається фінальний файл і виводиться у вікні на екран. |
