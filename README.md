# Заняття 9. Робота із сайтами та веб-парсинг (Web Scraping) у Python

Більшість актуальної інформації в сучасному світі зберігається на вебсайтах. За допомогою Python ми можемо програмно взаємодіяти з вебсерверами, надсилати їм запити, отримувати вміст вебсторінок та автоматично витягувати потрібні дані (наприклад, курс валют, прогноз погоди чи новини).

---

## 1. Як працює взаємодія із сайтами (Клієнт — Сервер)

Обмін даними в інтернеті відбувається за моделлю **«клієнт — сервер»** за протоколом **HTTP / HTTPS**:
1. **Клієнт** (браузер або ваша Python-програма) формує **запит (Request)** за певною URL-адресою.
2. **Сервер** отримує запит, обробляє його та повертає **відповідь (Response)**, яка складається зі **статус-коду**, **заголовків (headers)** та **тіла відповіді (body)** — наприклад, HTML-коду сторінки або даних у форматі JSON.

---

## 2. Основні види HTTP-запитів

HTTP-методи визначають, яку саме дію клієнт хоче виконати з ресурсом на сервері. Найчастіше на практиці використовують **GET** та **POST**, але всього існує кілька основних методів (CRUD-операцій):

| Метод запиту | Що означає | Призначення та принцип роботи | Приклад з життя |
| :--- | :--- | :--- | :--- |
| **`GET`** | Отримати (Read) | Запитує дані із сервера без їхньої зміни. Параметри запиту передаються відкрито прямо в URL-адресі (після знаку `?`). | Відкриття сторінки новин, пошук погоди, перегляд профілю. |
| **`POST`** | Створити / Відправити (Create) | Надсилає нові дані на сервер у прихованому тілі запиту, щоб сервер їх зберіг або обробив. | Реєстрація, вхід у акаунт (логін/пароль), відправка коментаря чи форми. |
| **`PUT`** | Повністю оновити (Update) | Повністю замінює існуючий ресурс на сервері новими даними. | Повне перезаписування анкети користувача. |
| **`PATCH`** | Частково оновити (Modify) | Змінює лише окремі поля існуючого ресурсу, не чіпаючи решту даних. | Зміна лише аватара або номера телефону в профілі. |
| **`DELETE`** | Видалити (Delete) | Видаляє вказаний ресурс із сервера. | Видалення посту, фото або товару з кошика. |
| **`HEAD`** | Отримати заголовки | Працює як `GET`, але сервер повертає лише службові заголовки без тіла сторінки. | Перевірка, чи існує файл на сервері та який його розмір перед завантаженням. |

---

## 3. Коди стану HTTP (Status Codes)

Кожна відповідь сервера містить тризначне число — **код стану**, який показує результат обробки запиту:

* **`1xx` (Інформаційні)** — запит прийнято, обробка триває.
* **`2xx` (Успіх)** — запит успішно виконано:
  * **`200 OK`** — стандартна успішна відповідь, сторінку/дані отримано.
  * **`201 Created`** — новий ресурс успішно створено (часто у відповідь на `POST`).
* **`3xx` (Перенаправлення / Redirect)** — сторінку перенесено за новою адресою (наприклад, `301`, `302`).
* **`4xx` (Помилка клієнта)** — неправильний запит або брак прав доступу:
  * **`400 Bad Request`** — сервер не зрозумів запит через неправильний синтаксис.
  * **`403 Forbidden`** — доступ заборонено (сайт може блокувати автоматичні запити).
  * **`404 Not Found`** — сторінку не знайдено за вказаною адресою.
* **`5xx` (Помилка сервера)** — збій на стороні самого сайту (наприклад, `500 Internal Server Error`, `503 Service Unavailable`).

## 4. Інструменти для HTTP-запитів у Python

### Вбудований модуль `urllib.request`
Входить до стандартної бібліотеки Python (не потребує встановлення). Дозволяє відкривати URL-адреси через об'єкт обробника (`build_opener()`, `open()`, `read()`), проте має громіздкий синтаксис, повертає дані у вигляді байтів (`bytes`) і вимагає додаткового ручного налаштування для передачі параметрів чи заголовків.

### Бібліотека `requests`
Стороння бібліотека, яка є стандартом індустрії для роботи з HTTP у Python завдяки простому та зрозумілому синтаксису.

* **Встановлення:** `pip install requests`
* **Основні методи:** `requests.get()`, `requests.post()`, `requests.put()`, `requests.patch()`, `requests.delete()`.
* **Ключові атрибути об'єкта відповіді (`response`):**
  * `response.status_code` — числовий код відповіді сервера (наприклад, `200`).
  * `response.content` — вміст відповіді у вигляді необроблених байтів (`bytes`), підходить для збереження картинок або файлів.
  * `response.text` — вміст відповіді у вигляді готового текстового рядка (`str`), зручного для читання HTML.
  * `response.headers` — словник зі службовими заголовками відповіді.

```python
import requests

response = requests.get("[https://httpbin.org/get](https://httpbin.org/get)")
if response.status_code == 200:
    print(response.text)

```

## 5. Основи веб-парсингу (Web Scraping)

**Парсинг (веб-скрейпінг)** — це автоматизований збір, аналіз та структурування інформації з вебсторінок за допомогою програмного коду.

### З чого складається вебсторінка?

Будь-яка вебсторінка побудована на мові розмітки **HTML**, яка складається з вкладених **тегів** (наприклад, `<div>`, `<p>`, `<span>`, `<a>`, `<h1>`) та їхніх **атрибутів** (`class`, `id`, `href`).

### Етапи парсингу сайту:

1. **Дослідження структури (DevTools):** у браузері натискаємо праву кнопку миші на потрібному елементі → **Перевірити (Inspect)**, щоб дізнатися, у якому саме тезі та з яким класом чи атрибутом зберігаються дані.
2. **Завантаження сторінки:** отримання HTML-коду сторінки за допомогою `requests.get()`.
3. **Пошук та витягування даних:** перетворення суцільного HTML-тексту на структуру даних і пошук потрібних тегів.

### Чому не варто парсити сайти через звичайні методи рядків (`.split()`)?

Розбиття тексту за тегами вручну працює лише для найпростіших випадків. Якщо на сторінці зміниться порядок атрибутів, з'являться зайві пробіли або вкладені теги, такий код одразу зламається. Для надійного пошуку по HTML використовують спеціалізовані парсери.

## 6. Бібліотека `BeautifulSoup` (`bs4`)

**BeautifulSoup** — бібліотека для швидкого розбору (парсингу) HTML- та XML-документів. Вона перетворює звичайний текстовий HTML-код на зручне **дерево об'єктів**, по якому можна легко шукати потрібні елементи.

* **Встановлення:** `pip install beautifulsoup4`
* **Створення об'єкта парсера:** `soup = BeautifulSoup(response.text, features="html.parser")` (де `"html.parser"` — вбудований у Python аналізатор HTML-розмітки).

### Основні методи та властивості `BeautifulSoup`:

* **`soup.find(tag, attrs)`** — шукає та повертає **перший** знайдений тег, що відповідає критеріям (або `None`, якщо нічого не знайдено).
* **`soup.find_all(tag, attrs)`** — знаходить **усі** теги, що відповідають критеріям, і повертає їх у вигляді списку.
* **`element.text`** — витягує лише чистий текст із тегу, відкидаючи саму HTML-розмітку.
* **`element.get("атрибут")`** або **`element["атрибут"]`** — дозволяє отримати значення атрибута тегу (наприклад, посилання з `href`).

```python
from bs4 import BeautifulSoup
import requests

response = requests.get("[http://quotes.toscrape.com](http://quotes.toscrape.com)")
if response.status_code == 200:
    soup = BeautifulSoup(response.text, features="html.parser")
    quotes = soup.find_all("span", {"class": "text"})
    for quote in quotes:
        print(quote.text)

```
