
# Винятки (Exceptions)

## 🎯 1. Що таке винятки?

Уявіть, що ви граєте в гру, де робот бігає по лабіринту. Раптом перед ним з'являється стіна, якої не було на карті, або закінчується батарейка. Якщо робот не знає, що робити — гра «вилітає».

У програмуванні такі ситуації називають **винятками (Exceptions)**:
* 💥 **Описка/Звичайна помилка:** Програма просто «падає» і вимикається.
* 🛡️ **Виняток:** Це надзвичайна ситуація. Програма каже: *«Ой, щось пішло не так! Але я знаю, як це виправити, і продовжу працювати далі!»*

---

## 📚 2. Часті винятки в Python

Коли Python бачить помилку, він дає їй власне ім'я:

| Назва винятку | Що це означає? | Приклад з коду |
| :--- | :--- | :--- |
| **`ZeroDivisionError`** | Ділення на нуль | `10 / 0` |
| **`ValueError`** | Неправильне значення | `int("привіт")` |
| **`TypeError`** | Несумісні типи даних | `"5" + 5` |
| **`IndexError`** | Неіснуючий елемент списку | `items[100]` (якщо є лише 3) |
| **`KeyError`** | Ключ не знайдено у словнику | `player["mana"]` |

## 🛠️ 3. Оброблення винятків (`try - except`)

Щоб програма не падала, ми обгортаємо «небезпечний» код у блок **`try - except`**:

```python
# Програма для ділення цукерок між друзями

try:
    candies = int(input("Скільки у тебе цукерок? "))
    friends = int(input("Скільки друзів? "))
    
    result = candies / friends
    print(f"🎉 Кожен отримає по {result} цукерок!")

except ZeroDivisionError:
    print("❌ Не можна ділити на 0 друзів! Усі цукерки залишаються тобі.")

except ValueError:
    print("❌ Будь ласка, вводь лише цілі числа, а не слова!")

```

---

## 🧩 4. Повна конструкція: `try - except - else - finally`

Для більшого контролю додають ще дві секції:

* **`else`:** Виконується **тільки якщо не було жодної помилки**.
* **`finally`:** Виконується **завжди** (навіть якщо була помилка).

```python
try:
    file = open("game_score.txt", "r")
except FileNotFoundError:
    print("❌ Файл із рекордами не знайдено!")
else:
    print("✅ Файл успішно відкрито!")
finally:
    print("🧹 Завершуємо роботу з файлами.")

```

## 🚨 5. Генерація власних винятків (`raise`)

Якщо ми хочемо **самі підняти тривогу** (наприклад, гравець ввів від'ємний вік), ми використовуємо команду **`raise`**:

```python
def check_age(age):
    if age < 0:
        # Сам викликаємо помилку
        raise ValueError("Вік не може бути від'ємним!")
    print(f"Твій вік: {age}")

try:
    user_age = int(input("Введи свій вік: "))
    check_age(user_age)
except ValueError as error:
    print(f"Ой! {error}")

```
