**Python та ООП**

**ООП (Об'єктно-орієнтоване програмування)** — це підхід до написання програм, у якому код будується навколо «об'єктів», а не лише окремих функцій чи змінних. Це схоже на моделювання реального світу: замість простого набору інструкцій ми створюємо деталі (класи) та конструюємо з них речі (об'єкти), які мають свої характеристики та вміють виконувати певні дії.

**Об'єкт** — це конкретний екземпляр (предмет), створений на основі «креслення» (класу). Він має власний стан (атрибути) та поведінку (методи).
* **Приклад з життя:** Якщо «Собака» — це загальне поняття (клас), то конкретний собака «Пес Патрон» (зі своїм віком, породою та вмінням гавкати) — це об'єкт.

**Клас** — це «креслення», шаблон або формочка, за якою створюються об'єкти. Клас описує, які атрибути та методи матимуть усі об'єкти, створені за його допомогою.

```python
# Приклад класу
class Dog:
    def __init__(self, name, age):
        self.name = name  # Атрибут
        self.age = age    # Атрибут

    def bark(self):       # Метод
        print(f"{self.name} каже: Гав-гав!")

# Створення об'єкта
my_dog = Dog("Патрон", 3)

```


**Метод** — це функція, яка знаходиться всередині класу і описує **дію**, яку може виконувати об'єкт цього класу (наприклад: `bark()`, `run()`, `fly()`).

**Атрибут** — це змінна всередині класу/об'єкта, яка зберігає його **характеристики** або властивості (наприклад: `color`, `age`, `name`, `speed`).

`self` — це посилання на конкретний об'єкт (екземпляр), для якого викликається метод. Він дозволяє методу звертатися до атрибутів саме цього об'єкта.

**Що таке конструктор класу і якою спеціальною назвою він позначається?** Це метод `__init__()`. Він автоматично викликається при створенні нового об'єкта і відповідає за задання початкових атрибутів.

**В ООП виділяють 4 основні принципи:**

#### 1. Інкапсуляція

**Пояснення:** Приховування внутрішньої логіки та деталей роботи об'єкта від зовнішнього світу та захист даних від випадкових змін.

* **Приклад з життя:** Кавоварка. Ви натискаєте одну кнопку (зовнішній інтерфейс), а внутрішній процес нагріву води та мелення зерна прихований усередині.
* **У Python:** Використання приватних атрибутів (з підкресленням `_` або `__`).

```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance # Приватний атрибут

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

    def get_balance(self):
        return self.__balance

```

#### 2. Спадкування (Inheritance)

**Пояснення:** Можливість створити новий клас (дочірній) на основі вже існуючого (батьківського), переймаючи всі його властивості та методи, а також додаючи нові.

* **Приклад з життя:** Клас `Тварина` -> Клас `Собака`. Собака є твариною, тому вміє дихати та їсти (успадковано), але додатково вміє приносити м'яч.

```python
class Animal:
    def eat(self):
        print("Ця тварина їсть.")

class Dog(Animal): # Dog успадковує Animal
    def fetch(self):
        print("Собака приносить м'яч!")

dog = Dog()
dog.eat()   # Виклик батьківського методу
dog.fetch() # Виклик власного методу

```

#### 3. Поліморфізм (Polymorphism)

**Пояснення:** Здатність різних об'єктів реалізовувати однаковий метод по-різному («один інтерфейс — багато реалізацій»).

* **Приклад з життя:** Команда «Подай голос!». Собака гавкає, кішка нявкає, а качка крякає. Команда одна, а результат різний.

```python
class Cat:
    def make_sound(self):
        print("Мяу!")

class Dog:
    def make_sound(self):
        print("Гав!")

animals = [Cat(), Dog()]
for animal in animals:
    animal.make_sound() # Один і той самий метод викликається у різних класів

```

#### 4. Абстракція

**Пояснення:** Виділення лише найважливіших характеристик об'єкта та ігнорування другорядних деталей для спрощення моделювання.

* **Приклад з життя:** Пульт від телевізора. Нам важливо знати, які кнопки перемикають канали, і не важливо, які мікросхеми передають інфрачервоний сигнал.


Всі типи даних у Python діляться на **змінні (mutable)** та **незмінні (immutable)**.

#### Основні типи даних:

1. **Числові типи:**
* `int` (целі числа): `5`, `-10`
* `float` (числа з плаваючою крапкою): `3.14`, `0.5`


2. **Текстовий тип:**
* `str` (стрічки): `"Привіт"`, `'Python'`


3. **Логічний тип:**
* `bool` (булевий): `True` або `False`


4. **Колекції (контейнери):**
* `list` (список): впорядкована **змінна** послідовність. Приклад: `[1, 2, "три"]`
* `tuple` (кортеж): впорядкована **незмінна** послідовність. Приклад: `(1, 2, 3)`
* `dict` (словник): колекція у форматі **ключ: значення**. Приклад: `{"name": "Оля", "age": 10}`
* `set` (множина): невпорядкована колекція **унікальних** елементів. Приклад: `{1, 2, 3}`



#### Головна відмінність (Змінність / Mutability):

* **Змінні (Mutable):** `list`, `dict`, `set`. Їхній вміст можна змінювати після створення (додавати, видаляти чи переписувати елементи).
* **Незмінні (Immutable):** `int`, `float`, `str`, `tuple`, `bool`. Спроба змінити значення створить новий об'єкт у пам'яті.



### Що таке `*args` та `**kwargs`?

Обидва синтаксиси використовуються у функціях, коли ми заздалегідь **не знаємо exact кількість аргументів**, яку передасть користувач.

#### `*args` (Positional Arguments)

* Дозволяє передавати у функцію будь-яку кількість **позиційних** аргументів.
* Усередині функції `args` згортається у **кортеж (tuple)**.

```python
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3))       # Результат: 6
print(sum_all(10, 20, 30, 40)) # Результат: 100

```

#### `**kwargs` (Keyword Arguments)

* Дозволяє передавати будь-яку кількість **іменованих** аргументів (ключ=значення).
* Усередині функції `kwargs` згортається у **словник (dict)**.

```python
def show_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

show_info(name="Іван", age=12, city="Київ")
# Виведе:
# name: Іван
# age: 12
# city: Київ

```

#### Коротка пам'ятка:

* `*args` — це **звіриний список/кортеж** із просто значеннями.
* `**kwargs` — це **словник** із парами `ключ=значення`.

Оскільки **kwargs усередині функції перетворюється на словник (dict), до нього застосовуються всі правила словників Python — кожен ключ повинен бути унікальним.
Якщо спробувати передати однакові ключі під час виклику функції, Python видасть помилку ще на етапі запуску.

Множина зберігає лише унікальні елементи (без дублікатів) і не має фіксованого порядку елементів (не можна звернутися за індексом `set[0]`).
Дублікати просто ігноруються, в множині залишиться тільки один такий елемент.


### Завдання: Порядок аргументів у функції

```python
def show(a, b, *args, **kwargs):
    print(a, b, args, kwargs)

show(1, 2, 3, 4, name="Анна", age=11)

```

* **Запитання:** Що потрапить у `a`, `b`, `args` та `kwargs`?
* **Відповідь:**
* `a = 1`, `b = 2`
* `args = (3, 4)`
* `kwargs = {'name': 'Анна', 'age': 11}`
